# 외부 실행 체크리스트

이 문서는 `ROADMAP.md`의 미완료 항목 중 저장소 코드와 CI만으로 완료할 수 없는 작업을
실행 가능한 체크리스트로 정리한다. 실제 장비, 계정 소유자 권한, 기관 제출 또는 장기간
현장 데이터가 필요한 항목은 아래 증빙이 확보될 때까지 완료로 표시하지 않는다.

## 공통 완료 기준

- [ ] 담당자, 목표 날짜, 대상 환경 또는 기관을 기록한다.
- [ ] 실행 명령, 설정 버전, 장비 펌웨어와 데이터 수집 조건을 기록한다.
- [ ] 결과 URL, 제출 번호, 보고서 또는 산출물 SHA-256처럼 재검증 가능한 증빙을 남긴다.
- [ ] 초안, 제출, 승인, 실증 완료 상태를 구분한다.
- [ ] 비밀키, 개인정보, 비공개 비행 로그는 저장소에 커밋하지 않는다.

## P755 사업화·법인화

- [ ] 사업 주체와 지식재산권 귀속을 확정한다.
- [ ] 법인 설립, 사업자 등록, 계좌·회계·보험 체계를 준비한다.
- [ ] 특허 출원 번호와 권리자 정보를 비공개 기록으로 관리한다.
- [ ] 완료 증빙: 법인 등록 상태, 권리 귀속 확인서, 사업 운영 책임자 승인.

## Phase 261-280 하드웨어 루프

- [ ] Pixhawk HITL에서 이륙, 순항, 회피, RTL, 착륙 시나리오를 반복 실행한다.
- [ ] Jetson 엣지에서 추론 지연, CPU/GPU 사용률, 전력과 열 스로틀링을 측정한다.
- [ ] RTK 위치 정확도와 통신 두절·복구 동작을 시험한다.
- [ ] 실비행 전 위험성 평가, 비행 승인, 지오펜스와 비상 절차를 검토한다.
- [ ] 익명화한 실비행 데이터셋과 데이터 카드를 작성한다.
- [ ] 완료 증빙: 장비·펌웨어 목록, 원시 로그 해시, 시험 보고서, 승인 문서 식별자.

## Phase 281-300 학술 영향

- [ ] Ablation과 기준선 실측을 고정 seed 및 공개 환경에서 재실행한다.
- [ ] 논문 본문, 부록, 재현 패키지와 그림의 수치를 교차 검증한다.
- [ ] Zenodo 아카이브를 만들고 DOI를 `CITATION.cff`와 논문에 반영한다.
- [ ] IROS 또는 목표 학회에 제출하고 K-UTM 표준 제안 채널을 확인한다.
- [ ] 완료 증빙: DOI, 제출 번호, 제출본 해시, 기관 수신 확인.

## Phase 328-329 생태계 공개

- [ ] `README.en.md`를 한국어 README와 기능·제약 수준까지 동등화한다.
- [ ] 대표 시나리오 스크린샷·영상 갤러리 자동 생성 작업을 배포한다.
- [ ] npm 조직과 provenance를 설정하고 `@sdacs/core`를 실제 발행한다.
- [ ] PyPI 프로젝트와 trusted publisher를 설정하고 Python wheel을 실제 발행한다.
- [ ] GitHub Discussions, 라벨, Good First Issue를 저장소 설정에서 활성화한다.
- [ ] 완료 증빙: npm/PyPI 버전 URL, GitHub 설정 화면 또는 API 결과, 갤러리 배포 URL.

## Phase 341-360 실제 배포

- [ ] 목포 해역과 전남 도서 좌표·공역 데이터를 권한 있는 최신 자료로 검증한다.
- [ ] 의료 배송 운영자, 지자체, 관제 기관과 90일 파일럿 범위를 합의한다.
- [ ] 개인정보·안전·장애 대응·데이터 보존 정책을 승인받는다.
- [ ] 파일럿 KPI를 수집하고 백서의 계산 근거를 독립 검토한다.
- [ ] 완료 증빙: 협약 또는 승인 식별자, 파일럿 로그 해시, KPI 보고서, 공개 백서 URL.

## Phase 361-380 실기 디지털 트윈

- [ ] 실제 기체 텔레메트리와 시뮬레이터 상태의 시간·좌표계를 교정한다.
- [ ] 지연, 패킷 손실, 센서 편향, 배터리 열화 모델을 현장 데이터로 보정한다.
- [ ] SIL/SITL/HITL/실비행 결과의 허용 오차와 실패 기준을 정의한다.
- [ ] 완료 증빙: 교정 데이터, 오차 보고서, 재현 명령, 승인된 모델 버전.

## Phase 410·412-420 국제 확장

- [ ] GUTMA 또는 관련 워킹그룹의 최신 제출 형식과 접수 채널을 확인한다.
- [ ] 해외 파일럿 제안서를 관할 규제와 파트너 요구사항에 맞춰 제출한다.
- [ ] 국제 벤치마크를 동일 하드웨어·데이터 조건에서 실측한다.
- [ ] 완료 증빙: 기고·제안 제출 번호, 접수 확인, 벤치마크 원시 결과와 환경 명세.

## Phase 493-499 차세대 이양

- [ ] 2027년 이후 차세대 트랙 공모 주체와 일정, 심사위원회를 구성한다.
- [ ] 적격 제안을 공개 기준으로 평가하고 선정 결정을 기록한다.
- [ ] 저장소, 도메인, 패키지 레지스트리, 아카이브와 운영 권한을 이양한다.
- [ ] 완료 증빙: 공모 공고, 선정 회의록, 권한 이양 확인, 후속 책임자 수락.

## 상태 갱신 규칙

각 항목의 증빙이 확보되면 이 문서와 `ROADMAP.md`를 같은 변경에서 갱신한다. 외부 제출은
“제출 완료”를 “채택 완료”로 표현하지 않으며, 실험 계획은 실측 결과로 간주하지 않는다.
