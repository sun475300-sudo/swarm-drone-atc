Motivation & Problem

Sub-400 ft urban airspace is rapidly filling with delivery drones, inspection UAVs, and eVTOLs. The 2023 FAA Part 89 Remote ID rule made enforcement real, yet the academic UTM literature still treats regulatory compliance as future work.

Existing methods attack one axis at a time:

  • CBS / MAPF — global optimality, no compliance
  • ORCA / VO — reactive avoidance, no compliance
  • NASA UTM CoO — regulatory framework, not runnable

No benchmark compares layer compositions on a shared suite that includes regulatory metrics.

Contributions
  • Hybrid 3-layer architecture — CBS global planner + APF reactive layer + ASTM F3411 regulatory bus, empirically validated with per-layer ablation.
  • Open benchmark suite — 10 scenarios (7 standard + 3 stress), 14 metrics, bit-deterministic Docker reproduction across 4 baseline systems.
  • Cross-domain pattern transfer — the CBS+APF composition transfers to StarCraft II swarm-micro, suggesting a portable multi-agent control pattern.

Each layer dominates on a distinct scenario subset. Removing any single layer causes degradation. The regulatory layer is uniquely required for RID-CR — neither CBS nor APF can satisfy it alone.

Cross-Domain Transfer (C3)

The CBS+APF composition pattern transfers to StarCraft II swarm-micro:

  • CBS-like resource reservation → prevents unit clumping at chokepoints
  • APF-like kiting forces → maintains optimal engagement distance
  • Testbed: Zerg swarm vs. Hard AI (SMAC environment)

This suggests the 3-layer composition is a portable design pattern for heterogeneous multi-agent control beyond UAV.
