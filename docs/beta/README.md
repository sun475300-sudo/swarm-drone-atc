## 피드백 수집

### 주간 설문 (NPS + 5문항)
```
1. SDACS를 동료에게 추천할 가능성 (0-10) → NPS
2. 가장 유용한 기능?
3. 가장 답답한 기능?
4. 추가하고 싶은 기능?
5. 자유 의견
```

### 사용 로그 분석
- P712 감사 로그 → 가장 자주 호출 API
- P718 Grafana → 응답시간/에러율
- 매주 보고서 발송
