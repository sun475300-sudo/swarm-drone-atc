## 🔴 발견된 이슈 및 권장 수정

### 이슈 #1: 테스트 수 표기 불일치
- **현재**: README.md:148, 662에 "3,425+ tests"
- **실측**: 3,083개 수집 (torch 미설치 환경)
- **추정**: torch 포함 시 3,400+ (5 모듈 × ~70 tests)
- **권장**: 환경 명시 — "3,400+ tests (torch 포함) / 3,083 (CPU only)"

### 이슈 #2: Monte Carlo Quick 모드 횟수
- **이전 주장**: 160회 (32 × 5)
- **실측**: **80회 (16 × 5)** — stderr 로그로 확인
- **권장**: 발표 자료에서 "Quick 80회"로 정정

### 이슈 #3: advisory_latency 메트릭 미작동
- **위치**: `simulation/analytics.py:184` `record_advisory_latency()` 메서드
- **문제**: 정의만 있고 시뮬레이터/컨트롤러에서 호출하지 않음
- **영향**: 모든 시뮬레이션의 P50/P99 = 0.00s (잘못된 출력 아님, 미측정)
- **권장**: "0.8초 응답" 주장은 시뮬 출력이 아닌 ICAO/UTM 문헌 기준임을 명시

### 이슈 #4: comms_loss 시나리오 SLA 미달
- **결과**: 97.59% (50대, 통신 손실 18회 주입)
- **SLA**: 99.5%
- **권장**: 발표에서 "통신 두절 시 일부 충돌 발생, RTL 안전 절차로 추가 피해 방지"로 정직하게 설명
