# 해양 소형선 감지·식별 시뮬레이터 — 기술 문서

> 대상 파일: `maritime_detection_simulator.html`
> 적용 도메인: 대형 모선(母船) 탑재 센서망에서 7~15 m 급 소형선 탐지·식별·충돌예측
> 본 문서의 모든 수치·공식은 시뮬레이터 소스 코드와 일치합니다.

---

## 1. 개요

본 시뮬레이터는 SDACS(군집 드론 공역통제 시스템)의 **비협조 표적 탐지·인식 기술**을 해양 도메인으로 이식한 사례입니다. 대형 모선에 탑재된 레이더와 AIS(선박자동식별장치) 수신기를 융합하여, 협조하지 않는 소형 선박(어선·레저보트·고속정)과 부표를 탐지·식별하고, 모선과의 충돌 위험을 예측합니다.

핵심 좌표·스케일 상수는 다음과 같습니다.

| 상수 | 값 | 의미 |
|---|---|---|
| `NM` | 1852 m | 1 해리 |
| `WORLD` | 6 × NM | 시뮬레이션 해역 반경(±6 NM) |
| `RADAR_NM` | 시나리오별 2.0~4.0 NM | 레이더 유효 거리 |
| `RADAR_H_M` | 12 m | 모선 레이더 안테나 높이 |
| `RADAR_MIN_M` | 150 m | 시클러터(sea clutter) 최소 탐지 거리 |
| `CPA_LOOKAHEAD` | 120 s | 최근접점 예측 지평 |
| `CPA_WARN_M` | 300 m | CPA 경고 임계 이격 거리 |

선종별 파라미터(레이더 단면적 RCS, 안테나 높이, AIS 탑재 확률, 식별 정확도):

| 선종 | RCS(m²) | 높이(m) | AIS 확률 | 식별 정확도 | 길이(m) | 속력(kn) |
|---|---|---|---|---|---|---|
| 어선 | 12 | 3.2 | 0.45 | 0.90 | 9~15 | 3~8 |
| 레저보트 | 5 | 2.4 | 0.25 | 0.85 | 7~12 | 5~14 |
| 고속정 | 3 | 1.9 | 0.10 | 0.82 | 10~15 | 18~32 |
| 부표 | 1 | 1.0 | 0.00 | 0.95 | 2~3 | 0 |

## 2. C1 — 레이더 물리 모델

### 2.1 레이더 수평선 (Radar Horizon)

지구 곡률로 인해 안테나·표적 높이에 따라 탐지 가능 최대 거리가 제한됩니다. 표준 대기 굴절을 반영한 근사식을 사용합니다.

```
수평선(NM) = 1.23 × (√h_radar + √h_target)      (h 단위: ft)
```

코드에서는 미터 입력을 받아 NM 환산하며(`radarHorizonM`), 모선 안테나 12 m + 표적 마스트(평균 2.4 m) 기준 약 **6.2 NM**가 산출됩니다. 표적이 수평선 너머에 있으면 RCS와 무관하게 미탐지로 처리합니다.

### 2.2 시클러터 블라인드

`RADAR_MIN_M`(150 m) 이내는 해면 반사(sea clutter)에 묻혀 탐지 불능으로 모델링합니다.

### 2.3 확률적 탐지 (4승 거리 법칙)

레이더 수신 전력은 거리의 4승에 반비례하므로, 탐지 확률 P_d를 다음과 같이 정의합니다.

```
R_ref = RADAR_NM × NM × (RCS / RADAR_REF_RCS)^(1/4)      (RADAR_REF_RCS = 5 m²)
P_d   = accMul / (1 + (distance / R_ref)^4)              (상한 0.98)
```

`accMul`은 기상 열화 계수(안개·폭풍 시 0.7~0.85)입니다. RCS가 큰 어선은 먼 거리에서도 높은 P_d를, RCS가 작은 고속정은 근거리에서만 안정적으로 탐지됩니다.

## 3. C2 — AIS·레이더 트랙 융합

각 표적은 `radarDet`(레이더 탐지)과 `aisDet`(AIS 수신)을 독립적으로 추적합니다.

- **AIS**: 거리 무관 수신하되 협조 선박만(부표 제외) 송신합니다.
- **레이더**: 위 C1 모델에 따라 확률적으로 탐지합니다.
- 둘 중 **하나라도** 성립하면 트랙을 생성하고, **둘 다** 성립하면 "RADAR+AIS 융합" 트랙으로 표기하며 `stats.fused`를 증가시킵니다.

융합 트랙은 비협조 표적 대비 위치·신원 신뢰도가 높아, 관제사가 우선순위를 낮게 둘 수 있는 근거가 됩니다.

---

## 4. C3 — EO/IR 합성 카메라 뷰

선택한 표적에 대해 EO(주간 광학)/IR(열영상) 센서 프레임을 합성하여 별도 캔버스에 표시합니다.

- **EO**: 하늘·해면 그라디언트 위에 선체·선실 실루엣과 조준 십자선을 렌더링합니다.
- **IR**: 차가운 해면(저온, 보라/검정)과 엔진부(선미)의 열점을 표현합니다. 열 강도는 고속정 > 어선 > 레저보트 순이며, 이는 추진 출력 차이를 반영합니다.

표적 크기는 거리에 반비례하여 확대/축소되고, CPA 경고 시 적색 오버레이가 표시됩니다.

---

## 5. C4 — COLREG 조우 분류

국제해상충돌예방규칙(COLREG)에 기반하여, 표적의 침로와 모선 방위 사이 각도 차이로 조우 유형을 분류합니다(모선을 원점·정지로 단순화).

| 유형 | 각도 차 | 의미 |
|---|---|---|
| HEAD-ON | < 22.5° | 정면 충돌 경로 |
| CROSSING | < 75° | 횡단 경로 |
| PASSING | < 126° | 통과·평행 |
| AWAY | ≥ 126° | 이탈 |

분류 결과는 라벨·트랙 리스트·상세 패널에 색상 배지로 표시됩니다.

---

## 6. C5 — 트랙 상세 + 트레일

표적 클릭(드래그와 구분) 또는 트랙 리스트 행 클릭으로 표적을 선택하면 상세 패널이 표시됩니다.

- 표시 항목: ID · 선종 · 탐지 소스 · 식별 신뢰도 · 거리/방위 · 속력/침로 · RCS · CPA/TCPA · 조우 유형
- 식별된 이동 표적은 `TRAIL_DT`(0.7 s) 간격으로 최대 `TRAIL_N`(8) 샘플의 항적선을 렌더링합니다.

---

## 7. C6 — CPA/TCPA 충돌 예측

모선을 원점·정지로 두고, 표적 상대속도 기준 최근접점(CPA)과 도달 시간(TCPA)을 해석적으로 계산합니다.

```
TCPA = -(x·vx + z·vz) / (vx² + vz²)
CPA  = |위치(TCPA)|        (0 < TCPA < CPA_LOOKAHEAD 인 경우만)
```

CPA < `CPA_WARN_M`(300 m)이면 경고를 발령하고 적색 예측선·배너 플래시를 표시합니다.

---

## 8. C6 리포트 · C9 검증 기록

- **PNG 리포트**: 헤더 + 3D 캡처 + KPI 패널(11지표) + COLREG 조우 요약 + 최근 이벤트를 단일 이미지로 합성합니다.
- **CSV(표적)**: 21열 텔레메트리(`id,type,len_m,...,cpa_m,tcpa_s,rcs_m2,hgt_m`)를 내보냅니다.
- **C9 검증 기록**: 시나리오 전환 시 직전 시나리오의 누적 KPI(탐지율·식별 정확도·AIS·융합·CPA)를 스냅샷하여 비교 표와 CSV로 제공합니다. 시나리오별 성능 정량 비교의 근거 자료입니다.

## 11. SDACS 본체와의 기술 연계

| 공통 1차 기술 | 드론(공역) | 선박(해양) |
|---|---|---|
| 비협조 표적 탐지 | 패시브 RF·레이더 | 레이더(RCS·수평선·클러터) |
| 협조 신원 융합 | Remote-ID | AIS |
| 충돌 예측 | CPA/TCPA(3D) | CPA/TCPA(2D 해면) |
| 규칙 기반 조우 판정 | 공역 회랑·우선순위 | COLREG 조우 분류 |
| 식별 정확도 모델 | 클래스별 정확도+오분류 | 선종별 정확도+오분류 |

두 도메인은 **비협조 표적의 탐지·국소화·분류·충돌예측**이라는 동일한 1차 문제를 공유하며, 센서 모델(전파 vs 광학/RF)과 차원(3D vs 2D 해면)만 도메인 특화로 교체됩니다.
