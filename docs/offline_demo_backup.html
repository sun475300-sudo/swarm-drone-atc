데모 시연 5단계 (말로 설명)

0:00
기본 비행 — 3D 공간에서 드론들이 같은 공역에서 움직이는 모습. "지금 보이는 것은 낮은 하늘의 가상 공역입니다. 여러 드론이 동시에 움직이고 있습니다."
1:00
드론 수 증가 — 드론이 많아질수록 경고와 회피 발생. "드론이 많아질수록 관제가 어려워집니다. 그래서 자동 예측과 회피가 필요합니다."
2:00
강풍 조건 — 환경 바꿔도 더 보수적으로 움직임. "바람이 강하면 안전 간격을 더 넓게 잡아야 합니다."
3:00
침입 드론 — 비협조 드론이 들어와도 주변 드론들이 회피. "예상하지 못한 드론이 들어와도, 주변 드론들이 위험을 줄이는 방향으로 움직입니다."
4:00
결과 지표 — 충돌, 근접, 어드바이저리 패널 표시. "발표에서는 한 장면을 보여드리지만, 실제 검증은 많은 조건을 바꿔 반복하는 방식으로 진행했습니다."
