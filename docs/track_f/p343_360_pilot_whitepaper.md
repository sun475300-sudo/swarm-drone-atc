# Phase 343–360 — 목포 해역·전남 도서 90일 파일럿 백서

> **성숙도 공시**: 이 문서는 Phase 341(`mokpo_harbor.py`)·Phase 342(`jeonnam_island_sites.py`)의
> 소프트웨어 구현을 바탕으로 작성된 **파일럿 계획 및 설계 백서**입니다.
> 실제 비행 허가, 기관 협약, 규제 승인은 별도 절차가 필요하며 이 문서가 그 근거가 되지 않습니다.

---

## 1. 개요

SDACS Phase 341–342에서 목포 해역 실 좌표계(`mokpo_harbor.py`)와 전남 도서 의료 배송 거점
데이터베이스(`jeonnam_island_sites.py`)가 완성됐다. Phase 343–360은 이 소프트웨어 기반 위에서
**90일 파일럿 운영 계획**을 수립하고, 실증 전 소프트웨어 검증과 운영 준비 체계를 정립하는 단계다.

| 항목 | 내용 |
|---|---|
| 파일럿 기간 | 90일 (권장: 2027 Q2–Q3) |
| 주요 지역 | 목포 해역 (Phase 341) + 신안·완도 도서 (Phase 342) |
| 핵심 시나리오 | 의료물품 배송, 해양 감시, 도서 지역 긴급 배송 |
| 소프트웨어 기반 | SDACS v1.5.0 시뮬레이터 + `mokpo_harbor.py` + `jeonnam_island_sites.py` |
| 성숙도 | beta (소프트웨어 검증 완료, 실 비행 검증 미완) |

### Phase 344 — 시뮬레이션 기반 사전 검증

**목표**: 실 비행 전 SDACS 시뮬레이터로 파일럿 시나리오 전수 검증

```bash
# 목포 해역 시나리오 시뮬레이션
python main.py simulate \
  --duration 3600 \
  --drones 5 \
  --seed 42 \
  --output data/results/mokpo_pilot_precheck.json

# 의료 배송 시나리오
python main.py scenario weather_disturbance \
  --runs 10 \
  --seed 42 \
  --duration 1800
```

**검증 항목**:

| 시나리오 | 시뮬레이션 횟수 | 합격 기준 |
|---|---|---|
| 정상 배송 (맑음) | 30회 | NMR < 0.1, 배송 성공률 > 95% |
| 기상 악화 (풍속 10m/s) | 20회 | 자동 RTL 발동 100% |
| 통신 두절 | 15회 | lost-link 프로토콜 준수 100% |
| NFZ 침범 시도 | 10회 | 자동 회피 100% |
| 비상 착륙 | 10회 | 지정 착륙 지점 도달 100% |

**목표**: 목포 해역 NFZ·회랑과 도서 거점을 통합 운영 지도로 구성

```python

    print(f"NFZ: {nfz.name} ({nfz.kind}), {len(nfz.vertices)}개 꼭짓점")

# 배송 거점 목록
```

**통합 운영 지도 구성 요소**:

### Phase 347 — 운영 절차서 (SOP) 작성

**목표**: 90일 파일럿 표준 운영 절차서 작성

#### 일일 운영 절차

```
1. 비행 전 점검 (30분)
   □ 기상 확인 (풍속 < 8m/s, 시정 > 1km)
   □ SDACS 시뮬레이터 사전 시뮬레이션 실행
   □ NFZ 최신 정보 확인
   □ 배터리 충전 상태 확인 (> 80%)
   □ 통신 링크 테스트

2. 비행 운영 (8시간)
   □ 배송 요청 접수 및 우선순위 결정
   □ 경로 계획 및 NFZ 충돌 검사
   □ 비행 허가 확인
   □ 드론 이륙 및 임무 실행
   □ 실시간 텔레메트리 모니터링

3. 비행 후 처리 (30분)
   □ 비행 로그 저장 및 분석
   □ 이상 사항 보고
   □ 장비 점검 및 충전
   □ 일일 운영 보고서 작성
```

#### 비상 절차

| 상황 | 조치 | 담당 |
|---|---|---|
| 통신 두절 | lost-link RTL 자동 발동 | 자동 (SDACS) |
| 배터리 부족 | 최근접 착륙 지점 자동 선택 | 자동 (SDACS) |
| NFZ 침범 감지 | 즉시 회피 기동 | 자동 (SDACS) |
| 기상 악화 | 전 드론 즉시 RTL | 운영자 명령 |
| 드론 추락 | 수색·구조 팀 출동 | 운영자 → 소방서 |

## 5. 성공 기준 및 Go/No-Go 결정

### Go 조건 (파일럿 실행 전)

- [ ] 비행 허가 취득 (국토교통부)
- [ ] 기관 협약 체결 (전라남도·신안군·완도군)
- [ ] 드론 기체 인증 완료 (항공안전기술원)
- [ ] 운영 인력 교육 완료 (드론 조종 자격증 보유)
- [ ] SDACS 시뮬레이션 사전 검증 통과 (Phase 344 기준)
- [ ] 보험 가입 완료 (제3자 배상책임보험)

### No-Go 조건 (파일럿 중단)

- 중대 사고 발생 (인명 피해 또는 재산 피해 > 1,000만원)
- 배송 성공률 < 80% (Day 30 중간 점검 기준)
- 규제 기관 운영 중단 명령
