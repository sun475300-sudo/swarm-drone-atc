# P746 — K-UAM 실증사업 신청 (국토교통부 2027 Q1)

## 사업 개요
국토부 K-UAM Grand Challenge 2단계 실증사업. 도심 회랑 비행 + 다중 기체 통제 + UTM 통합.

## 신청 자격
- 국내 법인 (대학 산학협력단 가능)
- UAM 분야 핵심 기술 보유 또는 컨소시엄 참여
- TRL 5+ 입증 (SDACS: TRL 6 — HITL 검증 완료)

## 컨소시엄 구성 (제안)

| 역할 | 기관 | 기여 |
|---|---|---|
| 주관 | 목포대학교 산학협력단 | SDACS 시스템·연구 |
| 참여 | KARI | UAM 회랑 시뮬·시험장 |
| 참여 | 한화시스템 | 양산 드론·통신 |
| 참여 | 안성시 | 시범 비행구역 |

## 제안서 핵심 (예시)

### 기술 차별점
1. **5계층 안전망 — 국내 최초 시스템 기여** (논문 인용)
2. **K-UTM 표준 호환** (P681-P690 구현 완료)
3. **재현성 패키지** — Docker + 10 시나리오 + 3 baseline (P703-P705)
4. **실기 검증** — 5기 스웜 HITL + 풍속 15 m/s 환경 시험 (Track A)

### 실증 계획 (3년)
- Y1: SITL + HITL 5기 → 안성 시험장
- Y2: 실외 10기 → 도심 회랑 시뮬
- Y3: 30기 + 인구 밀집지 야간 시범

### 예산 (예시)
- 총 30억 (3년)
- 인건비 60%, 장비 25%, 운영 15%
