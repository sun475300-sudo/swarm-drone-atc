# P747 — 해양수산부 항만 드론 시범사업

## 개요
maritime 시뮬레이터 자산을 활용한 항만 보안·해상 감지 솔루션. 부산·인천·울산항 3대 거점 항만.

## 기술 베이스 (이미 보유)

- 해양 시뮬레이터 9개 시나리오 (C1-C9) ✅
- C3 EO/IR 카메라 뷰 + adapter (P735) ✅
- C7 해안선·항로 3D 디테일 ✅
- C8 시나리오 3종 (storm, harbor, pirate) ✅
- 식별 정확도 모델 (DnI) ✅

## 항만 보안 application

| 시나리오 | 보안 가치 | SDACS 대응 |
|---|---|---|
| 미인가 선박 침입 | 테러·밀입국 방지 | DnI 분류 + RID 송신 강화 |
| 야간 어선 침범 | 어업분쟁 모니터링 | IR 카메라 + 자동 알람 |
| 위험 화물선 접근 | 폭발물·LNG 안전 | EO/IR 결합 + CPA 예측 |
| 항만 인프라 점검 | 자동 순찰 | 자율 경로 + 이상 탐지 |

## 컨소시엄

- 주관: 목포대 (해양 시뮬 보유)
- 항만공사: 부산항만공사, 인천항만공사, 울산항만공사
- 기술: 한화시스템 (드론·통신)
- 협력: 해양경찰청 (운영 노하우)

## 사업 단계

### Stage 1 — 1년차 (2026 하반기)
- maritime 시뮬레이터 + 실 항만 데이터 통합
- 가상 시나리오 30종 검증
- 항만공사 운영 매뉴얼 작성

### Stage 2 — 2년차 (2027)
- 실 드론 1기 부산항 시범 운영 (1개월)
- 야간 IR 감시 → 야간 어선 침범 5건 검출

### Stage 3 — 3년차 (2028)
- 3개 항만 5기 동시 운영
- 24/7 자동 순찰 + 해경 연동
