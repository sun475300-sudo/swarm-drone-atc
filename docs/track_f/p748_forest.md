# P748 — 산림청 산불 감시 협업

## 개요
야간·악천후 환경 IR 감시 모듈 + 자율 패트롤 알고리즘. 산림청·국립산림과학원과 협업.

## 기술 융합
- P735 EO/IR adapter
- P737 비협조 침입자 분류 → 산불 발화 패턴 인식으로 확장
- P742 eVTOL (장거리 산악 비행)
- Track A 실기 + 환경 시험 (P699)

## 시범 사업

| 단계 | 기간 | 내용 |
|---|---|---|
| Phase 1 | 6개월 | 강원·경북 산림 IR 데이터셋 구축 |
| Phase 2 | 1년 | SDACS 산불 탐지 모델 학습 + 검증 |
| Phase 3 | 1년 | 24/7 자동 패트롤 3기 시범 (춘천·안동) |

## KPI 목표
- 탐지 정확도 ≥ 90% (산불 vs 모닥불·반사광)
- 발화 후 평균 10분 이내 알림
- 오탐 < 5/주

## 산림청 연계 가치
- 야간 신고 후 도착 평균 45분 → 10분으로 단축
- 비행조종사 부재 시 자동 운영
- AI 발화 패턴 학습

## 예산
- 1단계: 5억 / 2단계: 8억 / 3단계: 10억
- 총 23억 (2.5년)
