# P749 — KISA / 국정원 보안 평가 (CSAP)

## 개요
SDACS Track C 시스템(FastAPI + DB + 관측성)에 대한 정보보안 감리. 공공기관 도입을 위한 필수 절차.

## 평가 항목 (CSAP 등급)

| 영역 | 항목 수 | SDACS 현황 |
|---|---|---|
| 접근통제 | 28 | P712 JWT/RBAC ✅ |
| 암호 | 14 | TLS 1.3 + bcrypt ✅ |
| 가용성 | 12 | P741 Raft HA (예정) |
| 감사 | 18 | P712 감사 로그 ✅ |
| 백업 | 8 | P714 + Daily backup 자동화 |
| 침해 대응 | 10 | P719 보안 감사 ✅ |
| 물리·환경 | 6 | AWS/NCP IDC 의존 |
| **총** | **96** | ~75% 충족 추정 |

## 준비 작업

### 사전 (3개월)
- [ ] 자체 점검 (KISA 체크리스트)
- [ ] 미흡 항목 보완 (P741 Raft, Daily backup, 침해 대응 매뉴얼)
- [ ] 보안 컨설팅사 자문 (예: SK쉴더스, 안랩)
