## 멘토링 일정 (예시)

### 학기별 (2학기 = 1년)
- W1: 코드 베이스 투어 + 환경 셋업
- W2: 시뮬레이터 실행·기능 시연 (군집·해양)
- W3: ROADMAP 후보 주제 결정
- W4-W6: 사전 조사·논문 읽기·PR 작성 연습
- W7-W12: 본 작업 (주차별 진척 보고)
- W13: 중간 발표
- W14-W18: 마무리 + 테스트 + docs
- W19: 최종 발표 + PR 머지
- W20: 다음 학번 인수

## 정기 미팅

- **주간**: 1시간 (Zoom or 오프라인)
- **월간**: 1회 코드 리뷰 (다른 학생 작업 cross-review)
- **분기**: 외부 멘토(연구실 OB) 초청 강의
