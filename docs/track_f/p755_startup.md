## 3. 사전 점검 체크리스트

### 3.1 시장 검증

- [ ] 기관 LOI 5건 이상 확보 (지자체·공공기관·민간기업)
  - [ ] 전라남도 드론 실증사업 LOI
  - [ ] 해양수산부 항만 드론 시범사업 LOI
  - [ ] 신안군 도서 의료 배송 LOI
  - [ ] 목포시 스마트시티 드론 LOI
  - [ ] 민간 드론 운영사 LOI
- [ ] 고객 인터뷰 10건 이상 (Pain Point 검증)
- [ ] 경쟁사 분석 완료 (국내 5개, 해외 3개)

### 3.2 기술 차별성

- [ ] 특허 5건 출원
  - [ ] APF + CBS 하이브리드 충돌 회피 알고리즘 (핵심)
  - [ ] 90초 선제 예측 CPA 알고리즘
  - [ ] 군집 드론 공역 관제 시스템 구조
  - [ ] 실시간 WebGPU 기반 시뮬레이션 방법
  - [ ] 도서 지역 의료 배송 경로 최적화 방법
- [ ] 논문 2편 게재
  - [ ] IROS 2026 또는 ICRA 2027 (국제 학술지)
  - [ ] 한국항공우주학회지 (국내 학술지)
- [ ] 기술 성숙도 평가 (TRL 4→6 달성)

### 3.3 팀 구성

- [ ] 핵심 인력 3명 확보
  - [ ] CTO (드론 제어 전문가)

## 4. TIPS 프로그램 신청 가이드

### 4.1 TIPS 프로그램 개요

| 항목 | 내용 |
|---|---|
| 지원 규모 | 최대 5억 (정부 1억 + 민간 4억 매칭) |
| 지원 기간 | 2년 |
| 주관 기관 | 중소벤처기업부 |
| 운영사 | TIPS 운영사 (VC, 액셀러레이터) |
| 신청 URL | https://www.jointips.or.kr |

### 4.2 신청 절차

```
1. TIPS 운영사 발굴 및 접촉
   - 드론·항공우주 분야 투자 경험 운영사 우선
   - 추천: 스파크랩, 퓨처플레이, 매쉬업엔젤스

2. 운영사 심사 통과
   - 기술 발표 (30분)
   - 팀 역량 검증
   - 시장 가능성 평가

3. 정부 심사 신청 (운영사 추천 후)
   - 사업계획서 제출
   - 기술 심사 (특허·논문 근거)
   - 최종 선정 발표

4. 협약 체결 및 자금 수령
   - 정부 1억 + 운영사 4억 매칭
   - 분기별 성과 보고
```

## 6. 향후 결정 시점 (Go/No-Go)

### Go/No-Go 기준

| 결정 시점 | Go 조건 | No-Go 시 대안 |
|---|---|---|
| **2027 Q4** (1차) | 논문 1편 + LOI 3건 + 팀 2명 | 라이선싱 모델로 전환 |
| **2028 Q1** (최종) | 논문 2편 + LOI 5건 + 팀 3명 + 자본 3억 | 사내 벤처 또는 라이선싱 |

### 2028 Q1 최종 평가 기준

- **시장 검증** ✓: LOI 5건 + 고객 인터뷰 10건
- **기술 차별성** ✓: 특허 5건 + 논문 2편
- **팀 구성** ✓: 핵심 인력 3명 + 자문단
- **자본 확보** ✓: TIPS 1억 + 엔젤 2억 = 3억
- **법무 정리** ✓: 기술 이전 협의 완료
