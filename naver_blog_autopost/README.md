# 🚁 Imperial Wings — 자동 포스팅 시스템

광주·전남 드론축구 동호회 **Imperial Wings**의  
**네이버 블로그 + 인스타그램(@giw2.025) 자동 포스팅 데스크톱 앱**입니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 네이버 블로그 자동 포스팅 | 드론 축구 주제 글 + 썸네일 이미지 자동 발행 |
| 인스타그램 자동 포스팅 | @giw2.025 계정에 1:1 이미지 + 해시태그 발행 |
| AI 콘텐츠 생성 | Gemini API 키 입력 시 매번 새로운 글 자동 생성 |
| 기본 원고 15종 | API 키 없이도 고품질 원고 자동 선택 |
| 스케줄러 | 매일 원하는 시간에 자동 포스팅 |
| 즉시 포스팅 | 버튼 클릭 한 번으로 두 플랫폼 동시 발행 |

---

## 🖥️ 설치 방법

### 1단계 — Python 설치
[https://python.org](https://python.org) 에서 **Python 3.10 이상** 설치  
> ⚠️ 설치 시 "Add Python to PATH" 반드시 체크!

### 2단계 — 앱 실행
`실행.bat` 파일을 **더블클릭**하면 자동으로 설치 후 실행됩니다.

## ⚙️ 사용 방법

### 기본 사용 (API 키 없이)
1. `실행.bat` 더블클릭
2. **계정 설정** 탭에서 네이버 아이디/비밀번호 확인
3. **포스팅 설정** 탭에서 시간 설정
4. `▶ 스케줄러 시작` 또는 `⚡ 지금 바로 포스팅` 클릭

### AI 자동 생성 사용 (선택)
1. [Google AI Studio](https://aistudio.google.com) 에서 Gemini API 키 발급
2. **계정 설정** 탭 → Gemini API Key 입력 (⚠️ 코드를 직접 수정하지 마세요!)
3. 이후 포스팅 시 AI가 새로운 드론 축구 글을 자동 생성

## 🔧 문제 해결

**Q: 로그인이 안 됩니다**  
A: 네이버 2단계 인증이 켜져 있으면 일시적으로 꺼주세요.

**Q: 브라우저가 열리지 않습니다**  
A: `실행.bat`을 다시 실행하면 Playwright가 자동 재설치됩니다.

**Q: 인스타그램 포스팅이 안 됩니다**  
A: Manus 환경에서 실행 시 확인 카드가 표시됩니다. 로컬 PC에서는 이미지 URL을 복사하여 수동으로 올려주세요.
