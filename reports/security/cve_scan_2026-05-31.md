### PYSEC-2026-120 — pyjwt 2.7.0
- **심각도:** LOW
- **직접 의존:** 아니오 (전이적 의존)
- **수정 버전:** 2.12.0
- **설명:** PyJWT is a JSON Web Token implementation in Python. Prior to 2.12.0, PyJWT does not validate the crit (Critical) Header Parameter defined in RFC 7515 §4.1.11. When a JWS token contains a crit array listing extensions that PyJWT does not understand, the library accepts the token instead of rejecting it. This violates the MUST requirement in the RFC. This vulnerability is fixed in 2.12.0.
